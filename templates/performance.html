Experimental Observations

Basic OT performs an independent Diffie-Hellman-based operation for every message pair. Its execution time increases approximately linearly with the number of transfers.

IKNP performs 128 Base OTs to establish the initial correlated random seeds required for OT extension.

Base OT setup dominates the total IKNP execution time in these experiments, while extension processing takes comparatively little time.

At 100 transfers, IKNP extension processing takes only a few milliseconds. However, total IKNP execution remains dominated by the repeated Base OT setup.

These results illustrate the potential of OT extension to reduce the cost per transfer when Base OT setup can be reused across a larger batch of transfers.
